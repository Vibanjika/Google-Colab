# Google-Colab
Google Colab notebook using Pandas to analyze patient data (age, weight, height). Includes data sorting and dropping, plus visualizations with Matplotlib: line plots, bar charts (horizontal &amp; vertical), pie charts, stacked plots, stem plots, subplots, axis customization, linspace, and color adjustments.
